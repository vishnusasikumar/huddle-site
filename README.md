# Huddle website

Landing, privacy policy and support pages for the Huddle app, served with GitHub Pages.

## Before publishing

When Huddle is live, change the "Coming soon to the App Store" button in index.html to your App Store link.

## Publish on GitHub Pages

1. Create a **public** repository, e.g. `huddle-site`, and upload these files to the root of the `main` branch.
2. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`, and save.
3. After a minute or two the site is live at `https://<username>.github.io/huddle-site/`.

## URLs for App Store Connect

- Privacy policy URL: `https://<username>.github.io/huddle-site/privacy.html`
- Support URL: `https://<username>.github.io/huddle-site/support.html`
- Marketing URL (optional): `https://<username>.github.io/huddle-site/`
